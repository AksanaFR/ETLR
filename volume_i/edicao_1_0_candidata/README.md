## Escopo científico

São 12 registros de matemática conhecida, 27 aplicações e 11 integrações internas, condicionais às premissas. CAL-01 é literal. H1–H3, suficiência dos IO candidatos e autogeração forte permanecem abertas. Os controles computacionais são sintéticos e delimitados. Consulte os limites antes de interpretar as provas como resultados sobre domínios físicos, mentais ou espirituais/astrais.

## Integridade

Extraia o ZIP em diretório novo. O arquivo SHA256SUMS.txt cobre todos os demais arquivos deste diretório, exceto ele próprio. O checksum do ZIP é distribuído ao lado do ZIP para evitar autorreferência. Execute `python reproducao/verificar_integridade.py` para conferir os arquivos. As instruções de reprodução usam Python 3 e a biblioteca padrão.
